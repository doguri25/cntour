# 충청남도 블록 탐방

블록으로 쌓은 충청남도 15개 시·군을 캐릭터로 걸어 다니며 둘러보는 3D 웹 페이지입니다.
이름표가 붙은 곳에 다가가 「살펴보기」를 누르면 설명이 나오고, 퀴즈를 맞히면 탐방 도장이 찍힙니다. 장소는 569곳입니다.

- 걷기: 조이스틱 · 방향키 · WASD
- 점프: 오른쪽 아래 버튼 · 스페이스바
- 살펴보기: 아래 파란 버튼 · E 키
- 시간(낮·노을·밤)과 날씨(맑음·비·눈·안개)를 바꿀 수 있습니다.

설치할 것 없이 `index.html`을 웹 서버로 열면 됩니다. Three.js(r187)를 함께 넣어 두었습니다.

## 수업 게임

`teacher.html`에서 학년(3학년: 시·군 하나 / 4학년: 충청남도 전체), 게임 방식(미션 탐방·도장 모으기·보물찾기), 제한 시간을 고르고 QR을 만들면 학생들이 같은 게임에 들어옵니다.
게임이 끝나면 모둠 이름이나 별명으로 기록을 올리고, 선생님 화면의 순위표에 모입니다(Firebase Firestore, 프로젝트 `cntour-tambang`).
